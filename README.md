# DMR — Confirmação de Presença

Versão pública sanitizada do sistema de confirmação operacional de presença por WhatsApp.

## Segurança desta cópia

Este repositório foi criado como um snapshot com histórico Git novo. Nomes, telefones, endereços, URLs de implantação e identificadores operacionais do projeto privado foram substituídos por exemplos fictícios.

Credenciais não fazem parte do repositório. Use os arquivos `.env.example` apenas como referência e mantenha valores reais exclusivamente em arquivos locais ignorados pelo Git ou nas configurações seguras do provedor de implantação.

Consulte [PUBLIC_RELEASE.md](PUBLIC_RELEASE.md) e [docs/SECURITY.md](docs/SECURITY.md) antes de executar ou implantar o projeto.
