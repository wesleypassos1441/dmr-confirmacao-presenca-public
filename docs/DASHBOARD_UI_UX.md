# Dashboard UI/UX

Direcao de interface:

- Operacional, clara e responsiva.
- Foco em leitura rapida de status diario.
- Formularios com labels visiveis e mensagens de erro simples.
- Dados sensiveis como telefone sempre mascarados em listas.
- Evitar textos promocionais, marketing ou visual decorativo excessivo.

Telas implementadas na primeira versao:

- Login.
- Painel do dia.
- Empresas.
- Turnos.
- Colaboradores.
- Relatorios com CSV e impressao/PDF do navegador.
- Contatos de alerta DMR.
- Logs/Auditoria.
- Configuracoes.

Revisao UI/UX aplicada:

- Navegacao lateral previsivel.
- Painel do dia com filtros por data, empresa, turno, prioridade e status.
- Formularios com labels visiveis.
- Tabelas densas para operacao diaria.
- Telefone mascarado nas listas.
- Estados vazios simples.
- Botoes com icones `lucide-react`.
- Render inicial resiliente, sem prender o operador em tela de carregamento.
