# Public sanitized release

This repository is a sanitized snapshot with a new Git history.

- Personal names, phone numbers, operational addresses, deployment URLs, and account identifiers from the private source were replaced with fictional examples.
- Real credentials and local runtime data are not included.
- Configure secrets only through local ignored environment files or the deployment provider.
- Never commit `.env`, WhatsApp sessions, logs, tokens, passwords, or service-role keys.

The private source repository and its history are intentionally not linked from this public snapshot.
